# 🏪 Vape Shop Management System

Система управления магазином с сохранением базы данных в GitHub для работы на Render.com

## 🌟 Функции

- ✅ Управление товарами и поставками
- ✅ Многопользовательская система для продавцов
- ✅ Автоматическое сохранение БД в GitHub
- ✅ Восстановление БД из GitHub при перезапуске
- ✅ Режим покупателя (только просмотр)
- ✅ Панель продавца с полным управлением

## 🚀 Быстрый старт на Render

1. **Создайте новый Web Service** на Render.com
2. **Подключите этот репозиторий** из GitHub
3. **Настройте сборку:**
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn app:app`
4. **Добавьте переменные окружения:**
   - `SECRET_KEY` (любая случайная строка)
5. **Нажмите Deploy**

## 🔧 Управление базой данных

База данных автоматически:
- ✅ Сохраняется в GitHub каждые 3 минуты
- ✅ Восстанавливается из GitHub при перезапуске
- ✅ Сохраняется при выходе из приложения

**Ручное управление:**
- 📥 **Восстановить из GitHub**: Кнопка в панели продавца
- 💾 **Сохранить в GitHub**: Кнопка в панели продавца

## 🔒 Безопасность

- Пароли хранятся в хэшированном виде (bcrypt)
- Автоматические бэкапы в GitHub
- Сессии с токенами
- Защита от CSRF

## 🛠 Технологии

- **Backend:** Flask, SQLite
- **Frontend:** Bootstrap 5, JavaScript
- **Хостинг:** Render.com
- **Хранение БД:** GitHub
- **Аутентификация:** Flask-Bcrypt

## 📞 Поддержка

При возникновении проблем:
1. Проверьте логи на Render.com
2. Убедитесь, что GitHub репозиторий подключен
3. Проверьте переменные окружения
4. Убедитесь, что файл `shop.db` есть в репозитории
